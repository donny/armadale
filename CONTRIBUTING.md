# Contributing to Armadale

Armadale is open source under the MIT License (`LICENSE`). Contributions
are accepted under the same license: by submitting a pull request or patch
you confirm that you wrote it, or have the right to submit it, and that it
is licensed under the MIT License like the rest of the project.

Build and test instructions are in `README.md`; the design contract is
`docs/DESIGN.md` and the working rules are `AGENTS.md`. The build must pass
with zero warnings before a change is submitted.
