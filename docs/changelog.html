  1. November 24, 2026

    Assistive tools can choose a tab in the tab bar

    A tab there now selects on an accessibility press, the one VoiceOver sends, and has a Rename action. Before, the press did nothing.

    Record a pane

    Record Pane… in a pane’s menu saves what the pane shows, never what you type, to a .cast file that asciinema play can play back. A pulsing red dot and a stop button in the pane’s header, and a red dot on its tab, show that it is recording.

0.1.2

Latest release November 17, 2026

Armadale updates itself from this version on; 0.1.1 and earlier get it by downloading it once. Download · Release on GitHub

  1. November 16, 2026

    Favorites are managed in the New Session chooser

    Drag a favorite to reorder it, or right-click it for Edit…, Move Up, Move Down and Remove. A running pane’s menu has Save as Favorite…, and Settings no longer has a Favorites tab.

    Add a host while starting a session

    The New Session dialog has New Host…: type a destination, with the aliases of your ~/.ssh/config offered as you type.

    Armadale updates itself

    Check for Updates… in the Armadale menu looks for a new version, and Armadale can look once a day if you allow it. Your sessions keep running through an update as they do through a quit, and Armadale asks first if any would end.

  2. November 14, 2026

    Sessions in tabs you are not looking at come back at launch

    After a relaunch they are reattached in the background, so an agent that finishes there still asks for your attention. Before, a session waited until its tab was shown.

    Armadale says when macOS ended your sessions

    With Armadale switched off under Background App Activity in System Settings, macOS ends local sessions a few seconds after a quit. Armadale now notices at the next launch and offers to open that setting.

    A safer saved layout

    Only one copy of Armadale uses a saved layout at a time, the layout file is backed up, and sessions Armadale cannot account for are left running. The file has a new format: 0.1.1 and earlier refuse a layout saved by this version, and leave it as it is.

  3. November 12, 2026

    Armadale comes to the front when it is asked for

    Settings… and Open Armadale in the menu bar item’s menu, and the question asked when quitting from the Dock or a script, no longer open behind the app you were in.

0.1.1

November 5, 2026

The first public release. Release on GitHub

  1. November 5, 2026

    A disk image with directions

    The download opens to a window that shows where to drag Armadale.

  2. November 4, 2026

    Open source

    Armadale is under the MIT License, with its source on GitHub. Help › Acknowledgements lists the components it bundles, and this site is live.

  3. October 31, 2026

    Panes are cards

    Each pane is a rounded card with a header for its status, title and working directory. The “…” in the header opens the pane menu: Split Right, Split Down, and a theme for that pane alone.

    Splits, tab switches and zoom leave programs alone

    They no longer reset the terminal modes of the program running in a pane.

  4. October 30, 2026

    A tab bar like the system’s

    The tab bar is drawn like the macOS 27 window tab bar. Tabs share its whole width, and the selected tab is scrolled into view.

    A quieter sidebar

    The selection highlight is gone: what a window shows is in semibold, with coloured icons in the active window. A click goes there, a double-click renames.

  5. October 29, 2026

    Keyboard Shortcuts moved from Settings to the Help menu

  6. October 24, 2026

    The New Session chooser

    A new tab, window or split no longer starts a shell by itself. Its pane lists your favorites, and New Session… opens a dialog for the place (this Mac or an SSH host), the directory, the profile and the options of Claude Code and Codex.

  7. October 23, 2026

    A clean exit closes its pane

    When a program exits with status 0, or you leave the shell with exit or ^D, the pane closes. A program that fails or is killed still shows Session Ended, now with its status or signal.

    Empty workspaces go away

    Closing a workspace’s last tab removes the workspace and its window.

0.1.0

October 23, 2026

The first build, made before Armadale was public. It was not published.

  1. October 20, 2026

    Rename in place

    Double-click a workspace, tab group or tab to rename it where it is.

    Full screen is remembered

    A workspace in full screen comes back in full screen after a relaunch.

  2. October 19, 2026

    Menu bar mode

    Quitting while sessions run asks first: keep them running with Armadale in the menu bar, or end them and quit.

    Signed and notarized

    Armadale is built as a Developer ID signed, notarized disk image.

  3. October 18, 2026

    Agents and attention

    A pane that rings the bell or sends a notification while you are not looking is marked on its tab, in the sidebar and on the Dock icon, and can post a macOS notification. The Claude Code and Codex profiles are set up for it.

    Remote hosts

    Sessions can run on SSH hosts, where they keep running through a quit or a lost connection and are reattached afterwards.

    Settings, themes and profiles

    Fonts, light and dark themes, Ghostty theme import, and profiles for the programs you start.

  4. October 16, 2026

    Persistent sessions

    Sessions keep running when Armadale quits. A relaunch restores windows and layouts and reattaches each session with its screen and scrollback.

    Workspaces, tab groups, tabs and panes

    A sidebar, a tab bar and split panes, with keyboard shortcuts, drag and drop, and a window per workspace.

  5. October 15, 2026

    The first commit

    A model, a saved layout and one window.
